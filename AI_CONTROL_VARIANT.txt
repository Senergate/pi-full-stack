Senergate v1.5.1 AI CONTROL C — Capacity Supervisor + Asset Adjustability
Source: v1.5.1 AI CONTROL B Battery Priority, derived from Baseline v1.5.1 Bugfix.

Main changes:
- Capacity Usage + Remaining Headroom supervisor with P/L1/L2/L3 hard-limit inputs.
- 100% = configured project hard limit; site limits default 0=disabled.
- Collapsible Capacity display embedded inside the existing Grid-Impedance / AI-control panel.
- Heatpump adjustability 1..100 mapping to minimum allowed AI level.
- Wallbox adjustability 1..100 mapping to minimum allowed AI level / lock.
- Battery Effective Threshold remains configurable; default 0.10 A.
- Capacity PRE-LIMIT derating respects operator adjustability boundaries.
- Battery charging is released if PRE-LIMIT is reached and HP/WB legal derating is exhausted.
- CRITICAL_UNRESOLVED state when HP + Wallbox are at their permitted floors and Battery cannot exit VUF critical.
- VUF flashes red with a 1-second period in CRITICAL_UNRESOLVED.
- Wallbox cross-mask changes use break-before-make command ordering (OFF before ON).
- CUF/Schieflast active control intentionally remains deferred.
